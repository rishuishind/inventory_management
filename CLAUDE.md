## Claude Code notes

- Before finishing a change, run `npm run typecheck && npm test && npm run e2e` and report the real
  results.
- Plan first for large new features (a new stage, schema redesign): send the owner a short plan
  and open questions, then build after they approve. Small fixes can go straight ahead.
- Commit or push only when asked. The GitHub repo is public.
